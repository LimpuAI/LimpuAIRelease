# Limpu

Limpu 桌面应用的**正式发布仓**——安装包、版本说明与变更历史。

Limpu 是一个运行在桌面上的通用智能体平台：生成式界面、多智能体协作、统一模型网关与沙箱安全执行——数据全程留在本地。

了解更多：[www.limpu.ai](https://www.limpu.ai)。

[English](README.md)

## 下载

前往 [Releases](https://github.com/LimpuAI/LimpuAIRelease/releases/latest) 页面获取最新安装包：

| 平台 | 资产 |
|------|------|
| Windows x64 | `limpu-<version>-windows-x86_64-setup.exe`（安装器）或 `.zip`（免安装） |
| macOS Apple Silicon | `limpu-<version>-darwin-aarch64.dmg` 或 `.zip` |
| macOS Intel | `limpu-<version>-darwin-x86_64.dmg` 或 `.zip` |

应用内置自动更新（签名清单）——新版本原地送达。
