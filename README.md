# Limpu

Official release repository for the Limpu desktop app — installers, release notes and changelog.

Limpu is a desktop-native agent platform: generative UI, multi-agent collaboration, a unified model gateway and sandboxed execution — with your data staying local.

Learn more at [www.limpu.ai](https://www.limpu.ai).

## Download

Grab the latest installer from the [Releases](https://github.com/LimpuAI/LimpuAIRelease/releases/latest) page:

| Platform | Assets |
|----------|--------|
| Windows x64 | `limpu-<version>-windows-x86_64-setup.exe` (installer) or `.zip` (portable) |
| macOS Apple Silicon | `limpu-<version>-darwin-aarch64.dmg` or `.zip` |
| macOS Intel | `limpu-<version>-darwin-x86_64.dmg` or `.zip` |

The app ships with a built-in updater (signed manifests) — new versions arrive in place.
